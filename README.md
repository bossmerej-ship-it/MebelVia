# MebelVia

Сайт мебельного магазина: каталог кроватей и матрасов, фильтры, подбор размера, обращение в WhatsApp и интерактивный 3D-просмотр кровати.

## Запуск

Установите Node.js 22 или новее, затем выполните в папке проекта:

```sh
npm ci
npm start
```

Откройте http://127.0.0.1:4173. Порт можно изменить переменной окружения `PORT`.

## Структура

- `dist/` — готовый статический сайт: HTML, CSS, JavaScript, фотографии, шрифты и 3D-модель. Файлы сайта редактируются непосредственно здесь.
- `source-assets/` — исходные изображения.
- `scripts/` — генерация 3D-модели и материалы.
- `test/` — проверки каталога, модели и 3D-просмотра.

## Проверки и 3D-модель

```sh
npm test
npm run build:bed
```

Готовая модель уже включена в проект. Повторная генерация нужна только при её изменении. Источники материалов и инструкции для Blender указаны в [scripts/materials/README.md](scripts/materials/README.md).

## Публикация

Разместите содержимое `dist/` на статическом хостинге. Отдельная сборка сайта не требуется; `preview.mjs` служит для локального просмотра.
