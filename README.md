# MebelVia

Сайт мебельного магазина: каталог кроватей и матрасов, фильтры, подбор размера, обращение в WhatsApp и интерактивный 3D-просмотр кровати.

## Запуск

Установите Node.js 22 или новее, затем выполните в папке проекта:

```sh
npm ci
npm start
```

Откройте http://127.0.0.1:4173. Порт можно изменить переменной окружения `PORT`.

## Публикация на Vercel

Публичный сайт: [mebelvia.vercel.app](https://mebelvia.vercel.app/). Проект `mebelvia` подключён к этому GitHub-репозиторию; новые push в `main` автоматически публикуются на том же адресе.

Проект публикуется как статический сайт из `dist/`. Настройки в `vercel.json` отключают установку зависимостей и сборку на хостинге: фотографии, шрифты, HDR-окружения и обе модели GLB уже готовы. Локальный `preview.mjs` на сервере не запускается.

Для импорта GitHub-репозитория используйте корень `./`, пресет **Other** и production-ветку `main`. `.vercelignore` ограничивает загрузку готовым сайтом и конфигурацией. Локальная привязка `.vercel/` не хранится в Git.

Повторная публикация через официальный CLI после входа и привязки проекта:

```sh
npx vercel --prod
```

## Структура

- `dist/` — готовый статический сайт: HTML, CSS, JavaScript, фотографии, шрифты и 3D-модель. Файлы сайта редактируются непосредственно здесь.
- `source-assets/` — исходные изображения.
- `scripts/` — генерация 3D-модели и материалы.
- `test/` — проверки каталога, модели и 3D-просмотра.

## Проверки и 3D-модель

```sh
npm test
npm run build:bed
npm run build:hanna
```

Готовая модель уже включена в проект. Повторная генерация нужна только при её изменении. Источники материалов и инструкции для Blender указаны в [scripts/materials/README.md](scripts/materials/README.md).

### Циклический каталог кроватей

`dist/bed-carousel.js` создаёт бесконечную горизонтальную ленту: перед «Виолеттой» доступна Monika, после Monika — снова «Виолетта». Клавиши ← / → переходят на одну карточку; верхних кнопок переключения нет. Свайпы используют нативную прокрутку с пополнением карточек во время жеста; горизонтальное колесо и трекпад передают всю длину движения в циклические координаты, включая несколько полных кругов за одно событие. Вертикальная прокрутка и Ctrl/Meta + колесо остаются у браузера. Конечный ползунок скрыт, поскольку у ленты нет первого и последнего положения.

Карусель сохраняет кольцевой порядок исходных карточек и компенсирует смещение без анимации. Копии карточек не создаются; обработчики фотографий и возврат фокуса из окна товара сохраняются. Фокус на товаре не блокирует ручную прокрутку. При навигации Tab автоматическая перестановка приостанавливается, чтобы можно было выйти из каталога. Изменение ширины сохраняет текущую кровать; при `prefers-reduced-motion` переходы мгновенные.

Ручная прокрутка свободная: CSS scroll snap отключён, после окончания жеста позиция не округляется. Лента сохраняет остановку между карточками; клавиши сдвигают её на ширину карточки, сохраняя дробное смещение. Новое ручное движение останавливает незавершённое движение с клавиатуры в текущей позиции.

Ширина карточки, gap и границы прокрутки измеряются при инициализации и изменении ширины, затем используются из кэша. Перестановка исходных карточек не требует повторных измерений на каждом wheel-событии; вся дельта движения применяется синхронно.

Лента `#beds` занимает всю ширину экрана без боковых полей и промежутков между карточками; внутренний отступ 16–48 px оставлен только у заголовка. На компьютере ширина карточек ограничена 560 px, на планшете помещаются две карточки, на телефоне — одна с видимым продолжением ленты. Фото используют `object-fit:contain` в области 4:3; правила не меняют матрасы и окно товара.

`dist/product-cards.css` задаёт оформление карточек кроватей и матрасов: белую область фотографии, тёплую подложку текста, короткую характеристику и нижнюю строку с действием. Цена кровати берётся из `summary`, подпись — из существующего описания изголовья в `specs`. У матрасов `summary` остаётся характеристикой, сохраняются жёсткость и пометка «Пример для подбора». Стили ограничены двумя сетками каталога и не меняют окно товара. На узком экране нижняя строка переносится без обрезки цены и кнопки.

После изменения карусели запустите `npm test` и проверьте в браузере: переходы через оба стыка без остановки, несколько полных кругов, клавиши ← / →, остановку между карточками в обе стороны, открытие и закрытие товара после перехода, смену ширины между телефоном и компьютером. При обновлении сайта измените версии CSS и модулей в HTML и импорте `app.js`.

### Мягкое появление разделов

`dist/navigation-motion.js` сохраняет мгновенное восстановление позиции при перезагрузке и возврате из истории. Плавность ссылок к разделам включается только после `pageshow` и двух кадров; перед уходом со страницы сбрасывается. Поэтому открытие ссылки на нижний раздел не прокручивает посетителя через промежуточные анимации и 3D-сцену. При `prefers-reduced-motion` переходы остаются мгновенными.

`dist/reveal.js` — независимый необязательный модуль без внешних библиотек. Он запускается при готовом DOM (или ждёт `DOMContentLoaded`, пока документ загружается) и использует IntersectionObserver и Web Animations API. Ориентир по ритму — [In Bloom](https://inbloomflowerast.vercel.app/): мягкое замедление и короткая последовательность появления.

Заголовки и текст поднимаются на 24 px, карточки — на 28 px за 700 мс; кнопки и строки вопросов — на 18 px за 650 мс. Задержки ограничены 120 мс. Индивидуальное свойство `translate` сохраняет существующий hover-transform карточек. Первый экран всегда остаётся видимым. Начальная позиция и прозрачность .5 задаются за экраном, эффект ставится на паузу и запускается только при фактическом входе в кадр. Поэтому анимация не расходуется вне экрана и не сдвигает уже появившийся текст назад. Поздние уведомления оставляют естественную позицию без нового движения. При первом входе сверху вертикальное смещение направлено вверх, при входе снизу — вниз; выход из зоны подготовки освобождает приостановленный эффект. Это предотвращает мигание при быстрой прокрутке, перезагрузке и восстановлении позиции. Быстрые жесты пропускают новые появления, уже запущенные плавно заканчиваются. Начало свайпа по тексту не обрывает эффект; кнопки, фокус и ссылки к разделам доступны сразу.

Блок доставки наблюдается целиком: текст приходит слева, грузовик — справа, одновременно за 700 мс со смещением 44 px. Повторное посещение блока не запускает эффект. Локальный `overflow-x:clip` предотвращает горизонтальное переполнение во время движения на телефоне.

Естественные стили всегда видимы: нет CSS, скрывающего контент до запуска JavaScript. При отсутствии API или ошибке эффекта содержимое остаётся доступным. `prefers-reduced-motion` отключает появления, в том числе при смене настройки во время просмотра. Карточки кроватей отмечаются просмотренными целой исходной группой; их перестановка в бесконечной ленте не перезапускает появление. Сцена Hanna, её предки, камера и подвижные узлы не участвуют в новых эффектах.

При открытии ссылки на нижний раздел невидимые блоки выше остаются ожидающими первого появления при прокрутке вверх. Переход к `#top` завершает движение только видимого содержимого и первого экрана; будущие появления каталога не отключаются.

`dist/entrance-motion.css` добавляет начальное появление заголовка и кнопок первого экрана за 650 мс: 18 px и прозрачность .6 → 1. Оно начинается средствами CSS при первом отображении и не затрагивает фотографию мебели. При `prefers-reduced-motion` эффект не применяется; фокус на кнопке сразу завершает её движение.

После изменений проверьте первое открытие, медленную и быструю прокрутку в обе стороны, ссылки на разделы, горизонтальную ленту, окно товара и три положения Hanna на компьютере и узком экране. Автоматические проверки находятся в `test/reveal.test.mjs` и запускаются вместе с `npm test`.

`dist/faq-motion.js` добавляет раскрытие и закрытие ответов «Перед покупкой» через высоту и прозрачность. Быстрые повторные нажатия продолжают движение из текущего положения; несколько ответов могут оставаться открытыми. Сохраняются нативные `<details>`, клавиатура и мгновенный режим `prefers-reduced-motion`; при ошибке модуля ответы работают без анимации. Размеры пересчитываются при изменении ширины и загрузке шрифта, после завершения фиксированная высота не остаётся.

### Hanna: подъём при прокрутке

Возврат из 3D-просмотра «Виолетты» проходит через состояние `closing`: общий слой модели, студийного фона и подписей затухает за 450 мс, а фотография и заголовок проявляются под ним. Нативный `showPoster()` вызывается после завершения opacity-перехода, чтобы последний 3D-кадр не исчезал раньше времени; модель остаётся в кэше и перестаёт участвовать в отрисовке. Таймер 600 мс завершает возврат, если браузер не отправил `transitionend`.

Повторное открытие во время затухания отменяет старое завершение и сохраняет ракурс; обычное открытие использует кэш через `dismissPoster()`. Поздняя загрузка не возвращает закрытую сцену и не забирает фокус. Escape работает так же, как кнопка возврата. При сокращённом движении, скрытии вкладки или уходе со страницы закрытие завершается сразу; невидимые ссылки первого экрана недоступны для фокуса, пока открыт 3D.

Hanna начинает готовиться заранее, за 600 px до входа в экран: после восстановления страницы назначается один свободный слот с пределом 500 мс (или таймер 300 мс без requestIdleCallback). Прокрутка не перезапускает этот срок; при входе в экран подготовка ускоряется. Геометрия перепроверяется после импорта просмотрщика: нижняя ссылка, скрытая вкладка и reduced motion не запускают лишнюю 3D. Без IntersectionObserver проверки видимости объединяются в один кадр по событиям прокрутки и размера, без постоянного RAF. Фотография загружается сразу с низким приоритетом и остаётся видна до готовности 3D. Обновления позы прекращаются сразу после выхода сцены из экрана; камера и анимация модели остаются прежними.

`dist/assets/models/hanna.glb` содержит отдельную анимацию `Lift`: основание, матрас и постель поднимаются вместе, короб и изголовье остаются неподвижными. `dist/hanna-lift.js` задаёт кадр по положению прокрутки; начало и конец сцены удерживают закрытое и открытое положения. Высота сцены резервируется до загрузки GLB, поэтому появление модели не сдвигает каталог после восстановления прокрутки. Перед первым показом модели сразу устанавливается соответствующая прокрутке поза. При ошибке загрузки или включённом сокращении движения остаётся исходная фотография без длинной sticky-секции; изменение высоты сохраняет положение видимого содержимого ниже сцены.

Отображаемая поза мягко следует за шагами колёсика с постоянной времени 68 мс, без перескока через цель. Новая цель измеряется один раз за кадр прокрутки; дополнительные кадры сглаживания повторно не измеряют страницу. После достижения точной позиции RAF останавливается. Перезагрузка, возврат к сцене и изменение размера сразу устанавливают актуальную позу. `scrollbar-gutter:stable` сохраняет ширину страницы при открытии окна товара; карусель не меняет ширину из-за исчезновения полосы прокрутки.

Внутренние крепления и детали используют меньше сегментов; геометрия ткани, прежние материалы, текстуры и все каналы `Lift` сохранены. Итоговая модель содержит 143 298 треугольников вместо 180 256 и занимает около 9,08 МБ вместо 10,10 МБ. Неподвижная мягкая тень под коробом включена в `FixedFrame` как unlit BLEND-плоскость; `shadow-intensity="0"` отключает повторный расчёт динамической тени при каждом seek. Model-viewer распознаёт теневую плоскость и исключает её из габаритов для кадрирования. Внутреннее затенение и материалы остаются прежними.

Модель восстановлена по исходному изображению Hanna и фотографиям [Sensor «Флит»](https://sensorsleep.ru/product/krovat-flit). Владелец подтвердил общий завод и другое торговое название. Опубликованные размеры и ссылки сохранены в [hanna-sources.json](scripts/materials/hanna-sources.json). Выбрано спальное место 160 × 200 см. Наружные габариты и точки крепления механизма оценены по фотографиям: это визуальная реконструкция для сайта, а не производственный чертёж.

Разместите содержимое `dist/` на статическом хостинге. Отдельная сборка сайта не требуется; `preview.mjs` служит для локального просмотра.
